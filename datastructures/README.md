# Hello World in C

A simple C program created as part of Activity 2: Git & GitHub Setup.

## Program Description

This program demonstrates a basic C program that prints a Hello World message to the screen.

## How to Compile

Open a terminal in the project folder and run:

```bash
gcc hello.c -o hello
```

## How to Run

On Windows:

```bash
hello.exe
```

Or:

```bash
.\hello.exe
```

On Linux/macOS:

```bash
./hello
```
